# Portfólio Ketlin Alencar — versão fiel ao PDF (Vue 3 + Vuetify)

Eu modelei o site para parecer com as “páginas” do PDF (cores, blocos grandes, fotos em círculo/arco e detalhes).  
As imagens do próprio PDF já estão em `public/assets/`.

## Rodar local
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
npm run preview
```

## Trocar WhatsApp / e-mail
No `src/App.vue`:
- `email`
- `whatsapp` e `whatsappLabel`

## Portfólio real (trabalhos)
- Coloque as imagens em `public/portfolio/`
- Edite `src/data/portfolio.js`
